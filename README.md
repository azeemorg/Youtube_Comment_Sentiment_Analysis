# YouTube Comment Sentiment Analysis 🎥📊

A Natural Language Processing project that extracts comments from YouTube videos and analyzes their sentiment using a multilingual BERT-based sentiment model. The project also explores sentiment distribution, text preprocessing, Bag-of-Words representation, and traditional machine learning classification.

## 🚀 Project Overview

YouTube comments contain valuable information about how viewers react to video content. This project uses the **YouTube Data API** to collect comments from a selected YouTube video and applies Natural Language Processing techniques to understand the sentiment expressed in those comments.

The project uses the multilingual BERT sentiment model:

`nlptown/bert-base-multilingual-uncased-sentiment`

The model predicts sentiment on a **1–5 star scale**, ranging from Very Negative to Very Positive.

## ✨ Features

* 📥 Extract YouTube comments using the YouTube Data API
* 🧹 Clean and preprocess text using NLP techniques
* 🤖 Perform sentiment analysis using multilingual BERT
* ⭐ Classify comments into five sentiment levels
* 📊 Visualize sentiment distribution
* ☁️ Generate a word cloud from comments
* ⚖️ Explore class balancing
* 🔤 Convert text into Bag-of-Words features
* 🧠 Train a Naive Bayes classifier as a secondary ML experiment
* 📈 Evaluate classification performance using accuracy, confusion matrix, and classification report

## 🔑 YouTube API Key

The project requires a **YouTube Data API v3 key** to retrieve comments.

For security reasons, the API key should **not be stored directly in the notebook or committed to GitHub**.

Use an environment variable instead:

```python
import os

DEVELOPER_KEY = os.getenv("YOUTUBE_API_KEY")
```

Set the environment variable before running the notebook.

> Never commit API keys, credentials, or `.env` files to a public repository.

## 🤖 Machine Learning Experiment

In addition to BERT-based sentiment analysis, the project includes a traditional machine learning experiment.

The sentiment labels generated by the BERT model are converted into numerical classes and used with a **Bag-of-Words** representation.

A **Gaussian Naive Bayes** classifier is then trained and evaluated.

This secondary classifier is intended as an experimental comparison rather than an independent ground-truth sentiment benchmark, because its training labels originate from the BERT sentiment predictions.

## ⚠️ Limitations

* Sentiment predictions depend on the pretrained BERT model.
* YouTube comments can contain slang, sarcasm, emojis, mixed languages, and context that may be difficult to classify correctly.
* The secondary machine learning classifier learns from BERT-generated labels rather than manually verified ground-truth labels.
* YouTube API access is subject to Google's API policies and quotas.
